# HW Submission Checklist

Please ensure all items are completed and checked before submission. Unchecked items will result in a **0 score** locally and on GitHub Actions.

- [x] Fill in your actual Student ID, Name, and GitHub Username in `student.conf`. Default values are NOT accepted.
- [x] Invite all current TAs as collaborators in your private repository.
- [x] Verify that all TAs have accepted the invitation (TAs accept daily; check the day after inviting).
- [x] Run `./mp.sh init` and `./mp.sh test` (or `./mp.sh grade`) and ensure the results match expectations.
- [x] Check and tick all items in `student.conf` and this file.
    - Example: Change `- [ ]` to `- [x]` to mark as completed.

> [!IMPORTANT]
> This `checklist.md` is for self-check purposes and is not legally binding. No leniency will be granted if skipped items lead to grading issues.
